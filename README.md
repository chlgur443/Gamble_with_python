# Python Casino Project

파이썬의 내장 GUI 라이브러리인 `tkinter`를 활용하여 제작한 카지노 미니 게임 런처입니다. 
단일 소지금 시스템을 공유하는 여러 가지 도박 게임(블랙잭, 비디오 포커 등)을 메인 로비에서 독립적으로 실행하고 즐길 수 있습니다.

## 주요 기능 (Features)

* **통합 런처 시스템**: 메인 로비 화면에서 원하는 게임을 클릭하여 개별 창(Subprocess)으로 실행합니다.
* **공용 지갑 (Shared Wallet)**: 모든 게임은 `wallet.txt` 파일을 통해 소지금을 공유합니다. 한 게임에서 돈을 잃거나 따면, 메인 로비 및 다른 게임에도 실시간으로 반영됩니다.
* **무한 충전 기능**: 파산 방지를 위해 메인 로비에서 언제든지 1000원 단위로 소지금을 충전할 수 있습니다.
* **손쉬운 확장성**: 새로운 게임을 추가할 때 메인 화면의 UI 코드를 수정할 필요 없이, 파이썬 파일 하나만 리스트에 복사해 넣으면 자동으로 런처에 버튼이 생성됩니다.

```text
    └── poker.py         # 비디오 포커 게임
```

## 포함된 게임 소개 (Games)

### 0. 공통룰
* **룰** : 
    * 배팅금액은 직접 설정가능하며 최소 100원 최대 배팅액은 없습니다.
    * 소지금이 부족하면 도박을 할수 없습니다.
    * 부족한 소지금은 메인화면에서 무제한으로 추가 가능합니다.

### 1. 블랙잭 (Blackjack)
* **룰**: 딜러와 1대1로 진행하며, 카드의 합이 21에 가장 가까운 사람이 승리합니다. 21을 초과하면 버스트(패배) 처리됩니다.
* **특징**:
  * 딜러는 17점 이상이 될 때까지 무조건 카드를 뽑는 카지노 표준 룰을 적용했습니다.
  * 승리 시 배팅금의 2배(원금 포함)를 획득합니다.

### 2. 비디오 포커 (Video Poker - 5 Card Draw)
* **룰**: 5장의 카드를 받은 후, 원하는 카드를 체크박스로 선택해 **1회 교환**하여 최종 족보를 완성하는 1인용 게임입니다.
* **특징**:
  * 완성된 족보의 난이도에 따라 배팅금의 0배 ~ 250배까지 배당금을 받습니다.
  * J, Q, K, A 원페어(Jacks or Better)는 원금을 반환하고, 10 이하의 로우 페어는 배팅금의 절반(0.5배)을 돌려주는 디테일한 룰을 적용했습니다.
  * 카드를 교환할 때 카드가 한 장씩 순차적으로 교체되는 연출을 적용하여 긴장감을 더했습니다.

## 실행 방법 (How to Play)

1. 이 저장소의 파일들을 하나의 폴더에 다운로드합니다.
2. 터미널(또는 명령 프롬프트)을 열고 해당 폴더 경로로 이동합니다.
3. 아래 명령어를 입력하여 메인 로비를 실행합니다.
   ```bash
   python main.py
   ```
4. 최초 실행 시 소지금 1000원이 자동으로 지급되며, 이후 원하는 게임을 클릭하여 배팅을 시작하세요!

## 🛠️ 개발자 가이드: 게임 추가 방법

새로운 게임(예: 슬롯머신)을 추가하려면 다음 2단계만 거치면 됩니다.

1. `gamble/` 폴더 안에 새로운 파이썬 파일(예: `slot.py`)을 생성합니다. (wallet 연동 필수)
2. 루트 폴더의 `main.py` 코드를 열고 상단 `GAME_LIST` 배열에 아래와 같이 한 줄을 추가합니다.
   ```python
   GAME_LIST = [
       {"name": "블랙잭 (Blackjack)", "script": "blackjack.py"},
       {"name": "포커 (Poker)", "script": "poker.py"},
       {"name": "슬롯머신 (Slot Machine)", "script": "slot.py"}, # 추가
   ]
   ```
3. 메인 화면에 '슬롯머신' 버튼이 자동으로 생성 및 정렬됩니다.
